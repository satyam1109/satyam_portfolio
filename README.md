# Satyam Singh — Portfolio

A dark editorial portfolio built with React and Vite. The visual system combines minimalist typography with subtle Matrix-inspired motion, an animated canvas backdrop, scan-line portrait treatment, scroll reveals, responsive project interactions, and a cursor-reactive micro-grid across dark surfaces.

The content is organized into professional systems, independent builds, experience, categorized skills, developer profiles, engineering writing, and contact sections.

## Run locally

```bash
pnpm install
pnpm dev
```

Create a production build with:

```bash
pnpm build
```

## Contact form

The form posts to FormSubmit and delivers enquiries to `satyamror1109@gmail.com`.

On the first real submission, FormSubmit sends a one-time activation message to that address. Open it and approve the form; later submissions will then be delivered automatically. No email credentials are exposed in the frontend.
